Question 1: Interpreting DESeq2 Output

Briefly explain what each of the following columns means:

baseMean log2FoldChange pvalue padj

The baseMean column represents the average normalized read count for each gene across all samples in the dataset. It reflects how strongly a gene is expressed overall, independent of whether its expression changes between conditions. Genes with higher baseMean values are generally expressed at higher levels.

The log2FoldChange column shows how much a gene’s expression changes between the two experimental conditions (post-exercise vs baseline). A positive value means the gene is expressed at higher levels after exercise, while a negative value means expression is lower after exercise. Because the value is on a log₂ scale, a value of 1 means expression doubled, and a value of −1 means expression was reduced by half.

The pvalue indicates the probability that the observed difference in gene expression occurred by chance. Smaller p-values suggest stronger evidence that the gene is differentially expressed between conditions. However, because RNA-seq experiments test thousands of genes at once, p-values alone are not sufficient to determine significance.

The padj column shows the adjusted p-value after correcting for multiple hypothesis testing using a false discovery rate (FDR) method. This correction reduces the likelihood of false positives when many genes are tested simultaneously. Genes with padj values less than 0.05 are typically considered significantly differentially expressed.

Volcano plot

A volcano plot shows both the size of expression change and the statistical significance of each gene.

res_df <- as.data.frame(res)
res_df <- res_df[!is.na(res_df$padj), ]

res_df$significant <- "Not significant"
res_df$significant[res_df$padj < 0.05] <- "Significant"

volcano_plot <- ggplot(res_df,
                       aes(x = log2FoldChange,
                           y = -log10(padj),
                           color = significant)) +
  geom_point(alpha = 0.6) +
  scale_color_manual(values = c("Not significant" = "grey",
                                "Significant" = "red")) +
  theme_minimal() +

Question 2: Volcano Plot Interpretation

What does the volcano plot show about gene expression after exercise?

The volcano plot shows that a subset of genes changes expression significantly after exercise, while most genes remain close to their baseline expression levels. Many of the significantly differentially expressed genes appear on the positive side of the log₂ fold change axis, indicating increased expression after exercise, although some genes also show decreased expression. The genes highlighted with higher −log₁₀ adjusted p-values represent the most statistically significant expression changes. Overall, the volcano plot demonstrates that exercise produces measurable transcriptional changes across multiple genes, supporting the conclusion that exercise has a coordinated effect on gene expression.
